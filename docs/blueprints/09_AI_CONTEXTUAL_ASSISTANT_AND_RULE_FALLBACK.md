# 09. Контекстен AI Ментор и Детерминиран Rule-Engine Fallback

## 1. Концепция и Бизнес Стойност
Модулът за **Контекстен AI Асистент (AI Ментор / Консиерж)** решава три класически проблема на стандартните чатботове в уеб приложенията:
1. **Елиминиране на халюцинациите и преразхода на токени (Smart Context Curation)**: Вместо да изпраща цялата база данни (стотици или хиляди обекти) в системния промпт при всяко съобщение, клиентски алгоритъм (`getSmartCuratedRecipes`) предварително филтрира и подава на LLM модела само **топ 10–12 най-релевантни обекта** в компактен JSON формат (ID, име, регион, тагове). Това спестява **до 90% от входните токени** и гарантира, че AI препоръчва реални записи от приложението.
2. **Интерактивни препоръки вместо сух текст**: Отговорът на AI е строго структуриран JSON обект, който освен експертен текст в 3 части връща и масив `recommended_entity_ids`. Интерфейсът автоматично превръща тези ID-та в интерактивни визуални карти с директна навигация към детайлната страница на обекта.
3. **100% Работоспособност без API ключ (Rule-Engine Fallback)**: Ако потребителят няма конфигуриран AI ключ или облачната услуга е недостъпна, приложението автоматично превключва към локален детерминиран **Rule-Based Engine** (`gourmetEngine.js`), който анализира ключови думи и тагове за `< 5 ms` и връща структуриран отговор със същия визуален интерфейс.

## 2. Абстрактна Схема на Данните (JSON Payload & Контекст)

## 3. Ключова Логика, Гранични Случаи и Защити

### 3.1. Интелигентно пред-филтриране на каталога (`getSmartCuratedEntities`)
Преди извикване на LLM, клиентският код оценява всички обекти в паметта спрямо думите във въпроса на потребителя (с дължина `> 3` символа):
```javascript
export function getSmartCuratedEntities(allEntities, userText, activeEntityId, maxItems = 12) {
  const words = userText.toLowerCase().split(/\s+/).filter(w => w.length > 3);
  
  const scored = allEntities.map(item => {
    let score = 0;
    const searchable = `${item.title} ${item.category} ${(item.tags || []).join(' ')}`.toLowerCase();
    
    // Точки за съвпадение с въпроса
    words.forEach(w => { if (searchable.includes(w)) score += 3; });
    
    // Бонус за текущо разглеждания обект
    if (item.id === activeEntityId) score += 10;
    
    return { item, score };
  });

  scored.sort((a, b) => b.score - a.score);
  
  return scored.slice(0, maxItems).map(({ item }) => ({
    id: item.id,
    title: item.title,
    tags: (item.tags || []).slice(0, 6).join(', ')
  }));
}
```

### 3.2. Плъзгащ се прозорец на паметта (6-Turn Sliding Conversation Memory)
- За да се поддържа естествен многостъпков диалог („А може ли да заменя шафрана с нещо друго?“), без контекстът да расте безкрайно, в промпта се подават само **последните 6 реплики** (`conversationHistory.slice(-6)`).
- Всеки контекстен селектор (напр. смяна на конкретен обект от падащото меню) може да бъде променян динамично по време на разговора.

### 3.3. Детерминиран Rule-Engine Fallback (`ruleEngine.js`)
Когато `hasAiKey() === false` или всички LLM модели върнат грешка:
1. Локалният двигател проверява въпроса срещу речник от тематични правила (напр. „заместител“, „техника“, „съчетаване“, „време/температура“).
2. Ако има избран конкретен обект (`activeEntityContext`), използва неговите метаданни (`expertTips`, `history`, `attributes`), за да сглоби богат, персонализиран отговор.
3. Маркира отговора със `source: 'local_engine'`, за да може интерфейсът да покаже дискретен индикатор „Локален експертен режим (без AI ключ)“.

## 4. UI/UX Архитектура и Потребителски Потоци

### 4.1. Поле за въпрос винаги най-отгоре (Top-Positioned Input Bar)
- За разлика от месинджърите, където полето за писане е забито най-долу, при експертен AI асистент **полето за въпрос, селекторът за контекст и бързите чипове (Quick Chips) са позиционирани най-отгоре**.
- Това позволява на потребителя веднага да зададе въпрос или да кликне бърз промпт без скролиране.

### 4.2. Плавно позициониране в началото на отговора (`scrollIntoView({ block: 'start' })`)
- Когато AI върне дълъг експертен отговор (3 секции + препоръчани карти), автоматичното скролиране до **дъното** на страницата би скрило началото на отговора и би принудило потребителя да скролира обратно нагоре.
- **Решение**: Прикачва се `ref` (`latestResponseRef`) към контейнера на **последния AI отговор** и при рендериране се извиква:
  ```javascript
  latestResponseRef.current?.scrollIntoView({ behavior: 'smooth', block: 'start' });
  ```
  Така потребителят винаги започва да чете точно от първото изречение на новия отговор.

### 4.3. Автоматичен мост от други модули (`location.state.autoPrompt`)
- Всяка страница в приложението може да изпрати потребителя към AI Ментора с предварително попълнен и автоматично стартиран въпрос чрез React Router `state`:
  ```javascript
  navigate('/ai-assistant', {
    state: {
      autoPrompt: 'Предложи креативна рецепта с наличните ми продукти: паста, чесън, пармезан.',
      entityId: 'spaghetti-aglio-olio'
    }
  });
  ```
- При монтиране `AIAssistant` прочита `location.state.autoPrompt`, стартира заявката автоматично и изчиства `window.history.replaceState({}, document.title)`, за да не се дублира при рефреш.

## 5. Готов Промпт за AI Агент (Copy-Paste за нов проект)

```markdown
Искам да имплементираш Контекстен AI Асистент (AI Mentor) с интелигентно куриране на контекста и локален Rule-Engine Fallback по следната спецификация:

1. **Smart Context Curation (`getSmartCuratedEntities`)**:
   - Не изпращай цялата база данни към Gemini API. Напиши помощна функция, която оценява обектите в каталога спрямо думите от въпроса на потребителя и подава в системния промпт само топ 10–12 най-релевантни обекта в компактен вид (`id`, `title`, `tags`), плюс пълните детайли на текущо избрания обект (ако има такъв).
2. **Структуриран JSON Отговор (3 секции + Препоръки)**:
   - Системният промпт трябва да изисква строг JSON обект на текущия език на потребителя с полета: `main_answer`, `expert_secret`, `historical_note` и `recommended_entity_ids` (масив от ID-та от подадения каталог).
   - Поддържай памет за последните 6 съобщения от разговора (`conversationHistory.slice(-6)`).
3. **Детерминиран Rule-Engine Fallback**:
   - Създай локален модул `ruleEngine.js`, който при липса на AI ключ или мрежова грешка анализира въпроса по ключови думи и генерира отговор в същия 3-частен JSON формат на база метаданните на обектите.
4. **UI/UX Изисквания**:
   - Позиционирай формата за въпрос, селектора за контекстен обект и бутоните с примерни въпроси (Quick Chips) най-отгоре на страницата.
   - Под всяко AI съобщение рендерирай интерактивни карти за всички валидни ID-та от `recommended_entity_ids`.
   - При получаване на нов отговор скролирай плавно до **началото** на новия отговор (`latestResponseRef.current?.scrollIntoView({ behavior: 'smooth', block: 'start' })`), а не до дъното на чата.
   - Поддържай автоматично изпълнение на входящ промпт през `location.state.autoPrompt`.
```
